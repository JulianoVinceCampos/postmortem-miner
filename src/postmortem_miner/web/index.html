postmortem-miner

Transforma um acervo de postmortems numa árvore de triagem e em SLIs candidatos. Determinístico e explicável: sem embeddings, sem chamada de modelo.

Acesso de demonstração: usuário julianovincedecampos, senha postmortem-miner. Os dados são um corpus sintético e o acesso é somente leitura.

Visão geral

Quantos padrões distintos explicam o acervo, e quanto dele fica de fora. Um incidente isolado é anedota; padrão é o que se repete. Comece aqui e use o menu para descer ao detalhe de cada análise.

Tamanho de cada padrão

Quantos incidentes cada padrão agrupa.

Sinais por camada

Onde o acervo fala mais alto: recurso, saturação, store, rede, aplicação, ciclo de vida, workload ou topologia.

Fora de qualquer padrão

Candidatos a observar. Se um destes repetir, deixa de ser anedota.

Árvore de triagem

Percorra de cima para baixo contra os sinais de um incidente ao vivo. Cada nó é uma pergunta binária sobre a presença de um sinal; a folha é o padrão provável e n é quantos incidentes do acervo caíram ali. A profundidade é limitada de propósito: ninguém percorre nove perguntas com produção parada.

Classificar incidente

Marque os sinais que você está observando agora. O resultado mostra o padrão provável e o caminho percorrido: quais perguntas foram feitas e com que resposta. É o caminho que torna a conclusão discutível, não o rótulo.

Resultado

Padrões

Cada padrão traz os sinais que o distinguem, os que estão sempre presentes, uma amostra da evidência original e, o que mais importa, em quantas ocorrências a causa raiz continua aberta. Enquanto isso não muda, recorrência é esperada.

Matriz sinal × padrão

Suporte de cada sinal distintivo dentro de cada padrão. Sinais nas linhas de propósito: com muitos padrões, a orientação natural gera uma tabela larga demais para ler.

Incidentes

O acervo inteiro, com o padrão atribuído a cada um e se a causa raiz foi endereçada. Clique numa linha para ver os sinais extraídos com a evidência que os originou.

Taxonomia de sinais

Todo token que o extrator sabe emitir, agrupado por camada. A taxonomia é deliberadamente grossa: a pergunta útil na triagem é "qual camada está falando", não uma classificação que ninguém lembra sob pressão.

Relatório

A mesma saída que a CLI escreve com mine --out. O dashboard não é uma segunda fonte de verdade: lê o mesmo pipeline.
